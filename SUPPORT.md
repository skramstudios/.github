# Support

Issues are the one support channel for Skram, Skram Vault, and Skram Tunnel.
There are no Discussions.

Open your issue on the product's own repository, not this one:

- [skram](https://github.com/skramstudios/skram/issues)
- [skram-vault](https://github.com/skramstudios/skram-vault/issues)
- [skram-tunnel](https://github.com/skramstudios/skram-tunnel/issues)

Reporting a bug or asking for a feature there gives you a template asking
for the details that make a report actionable. A suspected vulnerability
does not belong in a public issue — see [SECURITY.md](SECURITY.md) instead.
